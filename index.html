My Projects

LiftingCast Relay Server

Powerlifting meets run on Digital Referee Lights (DRLs) and LiftingCast, and when both depend on venue Wi-Fi, one bad connection can stop the whole meet. I created this instruction manual to help others run a Docker-based LiftingCast local server that acts as a relay to the cloud database, so the meet keeps running even when the connection doesn't.

Built with

  • Docker Desktop
  • WSL
  • DRLs
  • LiftingCast

What I learned

I learned how to use Docker to run the relay server, and got to know DRLs and LiftingCast in depth. I've run it for multiple meets, and it works perfectly.
