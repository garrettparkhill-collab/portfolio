My Projects

Liftingcast Relay Server

Powerlifting meets run on Digital Referee Ligths (DRLs), and LiftingCast and when both depend on venue Wi-Fi, one bad connection can stop the whole meet. I created this instruction manual to help others run a Docker based LiftingCast local server that acts as a relay to the cloud database, so the meet keeps running even when the connection doesn't.

Built with

  • Docker Desktop
  • WSL
  • DRLs
  • LiftingCast

What I learned

How to use Docker and running the relay server through it, along with more knowledge on the DRLs and liftingcast itself. I have run the server for multiple meets now and it works perfectly.
